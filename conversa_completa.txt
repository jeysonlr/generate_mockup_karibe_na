🧠 2. RENDER ENGINE (PASSO A PASSO PROFISSIONAL)

Agora o coração técnico.

🎯 Objetivo

Transformar:

imagem base + arte usuário → mockup final
🔷 ETAPA 1 — INPUT

Backend recebe:

{
  "product_id": "uuid",
  "variant_id": "uuid",
  "image_url": "upload.png",
  "transform": {
    "x": 100,
    "y": 80,
    "scale": 1.2,
    "rotation": 0
  }
}
🔷 ETAPA 2 — BUSCAR CONFIG

Buscar no banco:

imagem base do produto
área permitida
{
  "base_image": "camiseta.png",
  "area": {
    "x": 100,
    "y": 50,
    "width": 300,
    "height": 200
  }
}
🔷 ETAPA 3 — PROCESSAR IMAGEM
Usando Sharp

Fluxo:

1. carregar imagem base
2. carregar imagem do usuário
3. redimensionar arte
4. aplicar posição
5. aplicar rotação
6. compor imagens
🔷 ETAPA 4 — COMPOSIÇÃO

Pseudo fluxo:

canvas = base_image

overlay = user_image
→ resize
→ rotate
→ position(x,y)

canvas + overlay → final
🔷 ETAPA 5 — OUTPUT
gerar PNG
salvar
/storage/mockups/uuid.png
🔷 ETAPA 6 — RESPOSTA
{
  "mockup_url": "https://..."
}
⚠️ REGRAS IMPORTANTES
🔒 1. LIMITAR TAMANHO
evitar imagens gigantes
proteger servidor
🎯 2. RESPEITAR ÁREA

Nunca permitir:

imagem sair da área do produto
⚡ 3. PERFORMANCE

No início:

síncrono (ok)

Depois:

fila + worker

Frontend → upload imagem
        → envia config

        → retorna imagem
        → frontend mostra resultado
